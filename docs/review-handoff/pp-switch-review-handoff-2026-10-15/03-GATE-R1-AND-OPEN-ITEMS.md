## 本交接阶段明确不做

- 不因任何一条 CI 全绿而**自动**批准真实企业凭证。
- 不把模型工具参数里的 `user_id` 作为可信授权主体。
- 不自动将采集到的第三方网页 API 发布或执行。
- 不为 FEAT-03 另起大规模网关重构、K8s 专用架构或 GUI/RPA。
- 不重复执行 10 多轮已经有复审结论的零碎审计；仅对本轮实际接线的新攻击面做有针对性的回归。

## 重要风险提示

FEAT-05A 的 Agent Token 是访问控制面/API 的凭证：CLI `--token` 与生成后的 MCP 配置都可能产生本机进程参数、配置文件及截屏暴露风险。它**不应被放入 Git、公开截图、日志或模型上下文**。有安全 OS Keyring 后，优先考虑用安全的注入方式保护它（依赖实际 MCP 客户端配置能力）。这项风险与“后端旧系统 API Key 不暴露给 Agent”属于不同信任边界。
